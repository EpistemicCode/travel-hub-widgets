# Drop cover photos here

Save your Gemini-generated travel photos in this folder, named by preset:

| File | For |
|---|---|
| `hub.jpg` | Hub cover (1500×600) |
| `trips.jpg` | Trips module |
| `itinerary.jpg` | Itinerary module |
| `stays.jpg` | Stays module |
| `eats.jpg` | Eats module |
| `transit.jpg` | Transit module |
| `packing.jpg` | Packing module |
| `expenses.jpg` | Expenses module |
| `documents.jpg` | Documents module |
| `contacts.jpg` | Contacts module |
| `banner.jpg` | Section banner (1500×300) |

`.jpg` or `.png` both fine (if `.png`, pass `?photo=photos/hub.png`). Landscape 16:9 is ideal — the compositor crops to fit. Prompts: `Template/built/cover-image-prompts.md` (in the NotionTemplate repo).
